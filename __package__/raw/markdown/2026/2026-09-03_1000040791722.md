# 中外知名作家畅谈“APEC视野下的文学表达”

- **栏目**：中国作家网#新闻#各地文讯
- **发布时间**：2026-09-03 08:57:12
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0903/c403994-40791722.html

第六届粤港澳大湾区文学周正在广州举行，来自国内外的知名作家、专家学者相聚一堂，围绕“APEC视野下的文学表达”主题，探索在跨文化交流新语境下，文学表达从“区域叙事”向“国际对话”的拓展路径，共答“文明互鉴”“如何共鸣”的文学之问。
意大利翻译家、汉学家李莎结合自己多年的翻译实践指出，中国文学的表达已经容纳了当今数字时代世界共同关心的问题。她谈到自己翻译的阿来中篇小说《蘑菇圈》，早在多年前便以一个朴素的藏族女性故事回应了生态文学的核心关切；她翻译梁晓声的作品，看到中国文学对年轻人精神健康、心理问题的深刻书写。作为译者，她愿意把更多中国作家乃至各国的声音译介出去，让不同的文学彼此看见、彼此呼应。
秘鲁作家、翻译家莫沫在发言中表示，亚太地区首先是一个经济体，人们谈论的多是经贸与外交，很少谈及文化和文学，正因如此，在这样一个背景下探讨如何在亚太国家之间建立文化和文学的交流，显得格外有意义。她表示，中国文学在西班牙语世界的影响力还很小，彼此需要建立更多文化与文学上的沟通，期待联合更多出版社、作家和译者，共同把中国文学推介到西班牙语世界。
《香港文学》总编辑游江指出，APEC所代表的开放互通、多元共生，不仅是经济的合作与区域的互联，更是一种跨越边界的视野与胸襟，这也正是《香港文学》办刊41年来始终在探索的命题。他介绍，《香港文学》长期关注各地华文创作，推动华文对话，还开设新栏目刊发墨西哥、美国、澳大利亚等国作家的作品，让不同的文学“翻越太平洋相遇”。
《世界文学》原主编高兴表示，当今世界文学越来越是一门不断跨越和打破界限的艺术，跨界、杂糅和融合已成为普遍趋势，写作者要在融合中找到自己的声音，确立自己的风格，兴许能赢得更多文学的可能性，抵达更高的境界。
