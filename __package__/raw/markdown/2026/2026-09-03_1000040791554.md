# 第六届粤港澳大湾区文学周在广州启动

- **栏目**：中国作家网#新闻#各地文讯
- **发布时间**：2026-09-03 08:26:24
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0903/c403994-40791554.html

论坛现场
9月1日，由广东省作协主办的第六届粤港澳大湾区文学周在广州正式启动。作为文学周重点活动之一，粤港澳大湾区文学高质量发展论坛于当天举行，拉开了文学周的帷幕。论坛上半场聚焦“大文学观：边界与无限”，中国作协副主席李敬泽致辞并作主旨演讲。广东省作协党组书记、专职副主席向欣，香港作家联会执行会长、香港文学馆馆长罗光萍，澳门文化界联合总会会长吴志良，江苏省作协党组书记、书记处第一书记、副主席郑焱出席并致辞。广东省作协主席谢有顺主持活动。
李敬泽表示，粤港澳大湾区文学界以“文学一家人”的深情厚谊努力书写“粤港澳一家亲”的文学篇章，推动粤港澳大湾区成为新时代文学高质量发展最具活力、最具潜力的地区之一，成果丰硕、亮点突出。希望大家开阔眼界，与时代步伐同频共振，在时代大潮中深刻把握文化引领社会变革的重要作用，在人的全面发展中积极发挥文化创造美好生活的重要价值，在推进中国式现代化进程中成为时代风气的先觉者、先行者、先倡者，用心书写人民实践，真诚记录时代进步；拓展边界，为湾区文学开源引流，树立大文学观，繁荣互联网条件下新大众文艺，提升原创能力，开拓文学外延，积极推动文学与各种现代传播形态深度融合，赋能文化新质生产力；提升境界，助中华文化扬帆出海，把握“十五五”发展机遇，激发文化创新创造活力，推动大湾区建设成为连接和对话世界的文化桥头堡，成为中国文化自信的新典范。
李敬泽谈到，今天我们正在经历印刷文明向数字文明的转型，身处巨大的变化之中，我们或许需要回到一些最基本、最底层的逻辑和语法中去，重新思考和审视真实和虚构意味着什么，我们的语言和文学又意味着什么，在此基础上找到新的办法和出路，进而守护好文学的生机和生命。
向欣表示，推动粤港澳大湾区文学高质量发展要突出“联”字，激发赋能百业的“动力源”，推动三地资源共享、优势互补，促进大湾区文学成为助力千行百业的重要纽带；要着墨“特”字，营造文学生态的“湾区范”，记录生活的“小确幸”，描摹发展的“大图景”，探索心灵的“内宇宙”，开拓文学的“出海口”；要围绕“新”字，提升高质发展的“加速度”，打造开放包容、近悦远来的文学人才聚集地，在文化新三样、文化新质生产力的赛道上提速竞跑，以文学的笔力雕刻新征程的宏图盛景，为深化大湾区建设贡献文学力量。
罗光萍认为，大文学观绝非将文学的边界简单扩大，而是一种格局和胸襟，它要求我们跳出传统的文学观念，以一种更加开放、包容、多元的姿态去审视、创作和传播文学。粤港澳三地文缘极深，广东的厚重、香港的多元、澳门的融汇，共同铸成湾区文学丰富多彩的基因图谱。树立大文学观，需要我们打破地域、题材和传播的壁垒，共同走向更广阔的天地，在跨界和创新中寻找新的生长点，为新时代文学高质量发展作出湾区贡献。
“从2017年种下的一粒种子，到今天的一片森林，粤港澳大湾区文学的发展凝聚了无数人的心血与智慧。”吴志良分享说，粤港澳大湾区文学从来不只是文学命题，更是人心相通的桥梁。三地同属岭南文化圈，人相亲、习相近、心相通，不仅是一个经济共同体，更是一个文化共同体，而文学是最能触动深层情感、引起共鸣共情的文化表现方式。希望港澳文学能以此为契机，更好融入祖国文学大家庭，也为中国文学走向世界贡献港澳力量。
郑焱从“视野之大”“格局之大”“胸怀之大”三个方面破题，认为践行大文学观需要在跨学科对话中汲取新的思想资源，拓展自身表达疆域；自觉融入国家发展大局，在回应现实关切中彰显精神力量，在服务人民中实现价值升华；既深植于民族文化的厚土，也以开放的姿态参与人类文明对话，在文明互鉴中丰富自我。希望粤苏两地文学界建立更加紧密的交流合作机制，共同谱写新时代文学高质量发展的崭新篇章。
主旨发言环节，刘醒龙、徐则臣、余泽民、谢有顺等作家、翻译家、评论家围绕活动主题展开分享。向欣主持该环节。
刘醒龙从“时间就是金钱”这句俗语切入，追溯了它在不同时空中的出现情形——从晚唐诗人王贞白的名句“读书不觉已春深，一寸光阴一寸金”，到本杰明·富兰克林、托尔斯泰分别在18世纪和19世纪在书中写下“时间就是金钱”，再到20世纪80年代初深圳人的振臂一呼，“这句话历经一千多年，在地球上跑了一圈，又回到了它的诞生地。虽然出现的时间和地域不同，但其中所包含的文学精神始终如一”。他以此为例谈到，无论环境如何变化，与生命价值追求息息相关的文学精神一直传承下去，并在不同传播方式中形成共识。
徐则臣说，文学的样式随着时代发展在不断变化，“一个唐代的诗人在写诗写得非常得意的时候，永远不会想到小说会在若干年后成为这个世界的重要文体，而且一写就是几百上千万字”。不论是唐诗、宋词、元曲、明清小说等古代文体的嬗变，还是当下AI对人类创作的冲击，作家的身份和文学的概念都在被不断重塑。大文学观要求我们跳出既有文学看文学，一方面从文学的内部开疆拓土、创新创造，另一方面紧跟时代和生活的变化，发掘和呈现更多独特的个体经验，并将其上升为共有的文学经验和时代精神。
余泽民从世界文学的视角切入，认为大文学观的提出基于中国丰富的本土现实与当下媒体的快速变革，具有鲜明的本土性和当下性。他以自己丰富的创作经历为例，谈到文学翻译的最高使命是打破语言壁垒、跨越文化疆界，通过创作性转化促进平等的文学对话，这也是大文学观的一种特殊的践行方式。希望通过大文学观的相关讨论，能够让各种文学类型在同一个屋檐下和平共处，共同实现新的突破。
“大文学观之‘大’，不只是地域和题材，更是视野、格局和胸襟。”谢有顺认为，大文学观提示我们要对文学进行扩容，一是空间的扩容，打破人类中心主义，将文学还给多物种、多形态的世界；二是时间的扩容，打破线性时间观，让个体与更广阔的时空发生联结，既看到现在，也看到过去和未来；三是情感的扩容，从个体心绪的抒发迈向“宇宙共情”，“当我们可以与风对话、与万物交流时，就会看到一个更壮阔、更美好的世界”。这些扩容本质上是对世界重新“赋魅”，在深刻的谦卑中看到人与技术、与自然、与文明的和谐共生。
论坛下半场以“APEC视野下的文学表达”为主题，与会者深入探讨文学表达从“区域叙事”走向“国际对话”的拓展路径。当天还举行了两场文学交流活动，专家学者围绕“虚构与非虚构的融合共生”及“AI时代的写作：挑战、困境与希望”展开对话。
据悉，此次文学周历时8天，涵盖专业论坛、文学对谈、主题沙龙、基层采风、公益讲座等多元形式，其间还将举行“新大众文艺·广东进行时”交流座谈、“文脉同根·三江汇流”粤港澳作家对谈、广东文学发布、湾区文学之夜、“起笔珠江·三名笔会”、“回首与奔赴”新时代广东文学创作座谈、“粤派批评·时代回响”文学沙龙、“网络文学与中华文明叙事”主题交流、全国文学院联盟会议等活动，旨在为广大文学爱好者献上一场沉浸式、高质量的文学盛宴。
