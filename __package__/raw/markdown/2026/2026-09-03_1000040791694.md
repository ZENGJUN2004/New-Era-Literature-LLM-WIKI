# 第十届平遥影展“迁徙计划”推荐10部文学佳作

- **栏目**：中国作家网#新闻#各地文讯
- **发布时间**：2026-09-03 08:47:40
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0903/c403994-40791694.html

9月2日，第十届平遥国际电影展产业单元“迁徙计划・从文学到影视”推荐名单揭晓，艾伟、梁鸿、肖克凡、畀愚等作家创作的10部文学作品入选。
本届电影展“迁徙计划·从文学到影视”的推荐作品，包括以现实主义笔触描摹时代变迁、书写个体命运的作品。如影视剧《叛逆者》原著作者畀愚聚焦乡村青年在时代浪潮中向阳蜕变、商海沉浮的长篇小说《纯真年代》；胡性能丈量一代人青春理想、记录一代知识分子精神流变的中篇力作《猛犸象》；以及储福金以围棋的“定式”与“变着”隐喻人生，表达棋局有章法、人生无定解哲学思想的短篇小说《不知》。
推荐作品中，肖克凡的中篇小说《父亲和雕像》以华北电机厂的时代变迁为底色，聚焦父子两代工人的命运波澜与精神世界；杨遥的中篇小说《手铸》将目光投向传统铁匠，书写手艺人在时代冲击下的生存困境与突围之路。
多部作品将中华传统美学融入市井烟火，在日常生活的细节中呈现人性的温度。艾伟的长篇小说《春歌》注目杭州四十余年城市变迁与三代人的命运沉浮，让昆曲的古典意境与当代世俗人生形成深度互文；林那北的中篇小说《阳关三叠》以古琴串联起过往与现实，在缤纷世相里探讨救赎与情义；罗伟章的中篇小说《屋檐》则通过两代人合租生活的细腻描摹，在日常琐碎中传递邻里相守的人情温度。
此外，非虚构视角的介入为影视改编提供了极具社会价值与真实力量的文本基底。陈启文的《穿越人间的象群》描绘云南野生象群北上南归的过程，深度展现了中国在物种保护、人与动物和谐共处中的智慧方案；梁鸿的《要有光》用真挚的笔触记录青少年成长状况，寻求建立连接与共同成长的希望。
“迁徙计划·从文学到影视”由平遥国际电影展，与中国作家协会 “新时代山乡巨变创作计划”“新时代文学攀登计划” 的重点合作出版单位联合举办，致力于为影视行业推荐具有影视改编潜力的最新文学作品，为文学作品提供影视化合作与孵化平台。这一单元自第六届平遥电影展起设立，旨在促进文学与影视领域的资源对接及产业合作，推动优秀文学作品实现影视转化。四年来，该单元推荐作品共66部，已有《燕食记》《海边的向日葵》《钢的城》等26部文学作品在平遥亮相后，成功与影视公司达成版权交易、进入影视化轨道。
第十届平遥国际电影展将于9月24日至30日在山西晋中平遥古城内的平遥电影宫举办。“迁徙计划·从文学到影视”推荐作品作家及其出版编辑代表将受邀出席相关活动。届时，多位电影导演、制片人及文学评论家将作为特邀嘉宾与作家同台交流，向国内外影视版权采购机构、版权项目开发机构、影视制片公司、发行机构以及电影产业人士推介作品。此外，平遥国际电影展还将为推荐作品提供洽谈空间，促成作品代表与影视行业人士的一对一交流对话，推动影视化合作落地。
