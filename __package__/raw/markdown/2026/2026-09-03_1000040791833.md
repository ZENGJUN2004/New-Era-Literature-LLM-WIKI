# 汉文化网络文学专题创作扶持计划评选结果公告

- **栏目**：中国作家网#服务
- **发布时间**：2026-09-03 10:29:36
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0903/c403937-40791833.html

为进一步加强汉文化主题网络文学精品创作扶持力度，由中国作家协会网络文学中心、中共徐州市委宣传部共同主办的汉文化网络文学专题创作扶持计划，经组织专家论证评审，并报有关部门批准，确定10部作品入选，2026年8月26日至9月1日通过媒体平台进行了公示，现将入选名单予以公布。
