# 《湖南文学》创阅中心在岳阳楼区揭牌

- **栏目**：中国作家网#新闻#各地文讯
- **发布时间**：2026-09-02 08:14:08
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0902/c403994-40790757.html

8月31日，《湖南文学》创阅中心在岳阳市岳阳楼区望岳路街道北环路社区揭牌。湖南省作协副主席、毛泽东文学院院长、《湖南文学》主编沈念，《湖南文学》编辑部主任易清华，市文联党组书记李冈，区委副书记、宣传部部长辛兴参加揭牌仪式。
揭牌仪式研讨会现场。
沈念指出，岳阳历史文化底蕴深厚，文学创作人才辈出，“文艺岳家军”享誉省内。创阅中心的成立，是推动文学走向基层、服务群众的重要举措，将为广大文学爱好者和社区居民提供优质的创作、阅读与交流平台。他希望创阅中心持续开展作者交流、阅读分享等活动，把岳阳的优秀文学作品推向更广阔的舞台，真正让文学在基层落地生根、开花结果。
李冈表示，《湖南文学》作为湖南省文学创作的重要阵地，多年来深耕文学沃土，培育了一大批优秀作家，推出了众多有筋骨、有温度、有深度的精品力作。创阅中心落户岳阳楼区，是将省级文学平台延伸至社区群众家门口的生动实践，既为岳阳本土作者搭建了宝贵的学习交流平台，也为“书香岳阳”建设注入了新活力。
揭牌仪式现场。
辛兴代表区委、区政府向《湖南文学》杂志社、市文联表示衷心感谢。并表示，岳阳楼区将全力支持创阅中心建设发展，积极为创作交流、阅读分享、公益讲座等活动创造良好条件，搭好创作平台、做好阅读服务、讲好楼区故事，把创阅中心办成实实在在的文学阵地，推出更多具有楼区辨识度的优秀作品。
出席揭牌仪式的本土作家、诗人还有舒文治、孟大鸣、刘创、葛取兵、方欣来、张晓根、李年明、朱开见、拾柴、宋北丽、聂磊、陈迎、汪晓庆。
