# 粤港澳大湾区文学周举办 探讨文学创新发展

- **栏目**：中国作家网#新闻#各地文讯
- **发布时间**：2026-09-02 08:11:57
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0902/c403994-40790750.html

由广东省作家协会主办的第六届粤港澳大湾区文学周9月1日在广州启幕，以“大文学观：边界与无限”为主题的粤港澳大湾区文学高质量发展论坛同期举办。来自中外的作家、文学从业者等150余人，共同探讨如何进一步推动粤港澳文学界创新发展，促进大湾区与APEC成员经济体文学界之间文化交流互鉴。
粤港澳文学界已经集结起5000多名作家的骨干文学队伍。广东省作家协会党组书记、专职副主席向欣建议，推动粤港澳三地资源共享、优势互补，践行“大文学观”，繁荣互联网条件下新大众文艺，加强湾区题材、海洋文学、生态文学创作。同时，以文学串联文创产业、助力千行百业，促进文学IP全产业链开发。
“‘粤港澳大湾区文学’这一概念被提出到现在，将近九年。当年一个朴素的构想，如今已成长为枝繁叶茂的文学森林。”澳门文化界联合总会会长吴志良认为，粤港澳三地文学界应当进一步完善合作机制，共同打造知名文学品牌，建立人才培养、采风创作、产业合作的联动机制，推动文学与其他艺术形式的跨界融合。
香港作家联会执行会长、香港文学馆馆长罗光萍表示，粤港澳大湾区历来是中国与外部世界对话的窗口，随着以广东文学馆、香港文学馆、澳门文学馆为代表的文学基础设施不断完善，粤港澳三地要依托南国书香节、全民阅读活动周、香港海洋文学等品牌活动，让民众在阅读中感受到文学的力量与情感的认同。
中国作家协会副主席李敬泽表示，粤港澳大湾区处于中外文化的交汇点、撞击点、融合点，作家和文学工作者要致力于推动大湾区建设成为连接世界、对话世界的文化桥头堡，成为中国文学“破圈跨界”的辐射地、文化“新三样”的出海口，成为中国文化自信的新典范。
当天下午，还举办了以“APEC视野下的文学表达”为主题的论坛，以及“虚构与非虚构的融合共生”“AI时代的写作：挑战、困境与希望”等主题圆桌交流活动。
本次文学周活动期间，还将举办“新大众文艺·广东进行时”交流座谈会、湾区文学之夜、名家面对面文学对谈活动、“回首与奔赴”新时代广东文学创作座谈会等23场文学交流活动。
