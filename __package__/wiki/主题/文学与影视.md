# 文学与影视

「文学与影视」是新时代文学媒介融合的核心议题：从中国第一部电影《定军山》、第一部电视剧《一口菜饼子》携带文学戏剧基因诞生，到网络文学 IP 撑起国产影视半壁江山，文学精神与视听语言的相互转化被称为「双向奔赴」。

## 关键信息
- **核心场域**：第二十一届中国长春电影节「中国文学新力量」系列活动（据 2026-09-03 中国作家网《小说里有戏——文学与影视何以双向奔赴》，孟海鹰、任姗姗）
- **关键数据**：据《2025 年文学改编影视作品蓝皮书》，2025 年度口碑与热度俱佳的 100 部国产剧集中，文学改编作品占 59%；据中国社会科学院《2025 中国网络文学发展研究报告》，2025 年网文 IP 改编市场规模达 3676.1 亿元
- **时代语境**：我国网民规模达 11.25 亿人、微短剧用户超过 7 亿、生成式人工智能用户规模突破 6 亿（中国传媒大学教授赵晖引述）

## 时间线
- **（影史起点）**：中国第一部电影《定军山》与中国第一部电视剧《一口菜饼子》携带中国戏剧和中国文学基因诞生。
- **2026 年（第二十一届）**：中国长春电影节「中国文学新力量」系列活动举行，莫言为青年编剧潘耕的博士论文题写「小说里有戏」五字；电影《给阿嬷的情书》获本届长春电影节评委会大奖。
- **2026-09-03**：中国作家网「理论评论·争鸣」发布孟海鹰、任姗姗《小说里有戏——文学与影视何以双向奔赴》。

## 详细内容

### 各家观点（观点归原作者）
- **全勇先**（鲁奖作家，《悬崖》《悬崖之上》编剧）：剧本是关于声画的艺术；任何时候不能忽略作品的精神属性，更不能「物化」影视产品——一切艺术的抵达依赖于人类最基本的情感、审美和共情能力。
- **潘耕**（曾参与电视剧《红高粱》改编）：总结改编「加减乘除」方法论——剥离不适宜视听呈现的部分、丰富人物群像增添细节、放大标志性文学意象升华为视听高潮、审慎筛除违背大众情感逻辑的情节；「守住原著的精神内核，是媒介转化的第一要义」。
- **王小枪**（《对手》《县委大院》编剧）：快节奏催比拼信息密度是对文学母本余韵的破坏；「好的文学懂得分寸」，在戏剧张力拉满时保留一分余韵；技术可以量化、反转可以设计，唯独真诚无法通过数学和算法推导。
- **管平潮**（网络作家）：文学 IP 影视化的密码是写强共鸣的好故事，「密码是明码」，重中之重是作品要有清晰的思想内核。
- **赵晖**（中国传媒大学）：人人都是生产者、传播者、接受者；文学正以视听化的方式走进生活，并与文旅、文博共振。
