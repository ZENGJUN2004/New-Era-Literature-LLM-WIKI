# 中国文学新力量系列活动

「中国文学新力量」系列活动是第二十一届中国长春电影节（2026-08-23 开幕）的重点活动之一，2026-08-24 在长春举行，聚焦文学 IP 影视转化与青年创作人才培养。

## 关键信息
- **时间**：2026-08-24（电影节 08-23 开幕）
- **地点**：吉林长春
- **主办**：中国作协、吉林省委宣传部指导；吉林省作协、中国作协社会联络部、长春市委宣传部主办
- **背景**：长影集团为"新中国电影的摇篮"（《白毛女》《林海雪原》《英雄儿女》均源自文学根脉）

## 时间线
- **2026-08-23**：第二十一届中国长春电影节开幕（中央广播电视总台与吉林省人民政府共同主办）。
- **2026-08-24**："中国文学新力量"系列活动举行：发布 2026 年度最具转化价值文学 IP 吉林中青年作家作品推荐榜（15 部）；签署文学 IP 数字转化暨长影 IP AIGC 转化战略合作协议；启动"AI 尚吉林"原创文学作品征集活动。

## 详细内容

### 邱华栋致辞三个方向（2026-08-24）
中国作协副主席邱华栋指出文学的生产方式、传播载体、审美风尚、读者构成已发生结构性变化，未来应：
1. 树立开放包容的"大文学观"，在新大众文艺中回应时代；
2. 推动文学与影视深度融合，构建双向赋能的良性机制；
3. 厚植培育沃土，壮大担当时代使命的"中国文学新力量"。

### 2026 年度最具转化价值文学 IP 吉林中青年作家作品推荐榜（15 部）
史玥琦《苹果梨》、戎禹《游向月亮》、刘策《虚构心跳》、孙昱莹《把头》、张君怡《救猫咪》、张月白《管中窥豹》、修瑞《矮檐》（以上小说）、孙翠翠报告文学《王希季：此生无悔铸天箭》、张紫华儿童文学《人参鸟飞翔》、小鱼大心《彼岸有妖》、李忠飞《拥抱我们的星辰大海》、莫伊莱《罪恶无形》、弈青锋《大道为巅》、妞妞蜜《八零烟火人家》、封尘往昔《清白之罪》（以上网络文学）。

### "文学 IP 影视化密码"分享汇要点（观点归各嘉宾）
- **全勇先**（中国作协全委会委员，中篇小说《秘密》获第九届鲁迅文学奖，首发于长春《作家》杂志）：电影快速发展中可能缺乏"经典叙事"因素，其本质在于有逻辑、有情感、有审美，绝非依靠大数据决策；电影人应以文学作"根"，重塑与观众之间的信任。
- **王小枪**（中国视协编剧委员会副会长）：技术可以量化、反转可以设计，"唯独真诚感，是无法通过数学和算法推导出来的"；不把人物神化、不把痛苦奇观化；"留白是需要勇气的"，好的影视转化能在张力最满时保留余韵。
- **管平潮**（浙江省作协副主席）：好故事的重中之重是清晰的思想内核；情感浓度、共鸣强度、剧情张力、反转密度及亲切生动的"活人感"为 IP 影视转化增色；AI 大模型解决资料查询是"后知"，博览群书才激发"先知"。
- **赵晖**（中国传媒大学教授）：新大众文艺正改变文学影视化生产逻辑——内容源头从经典走向多元（网文、同人二创、大众原创）；生产模式趋向互动（用户评论反向介入 IP 遴选与剧本打磨）；产业链更依靠平台（长剧、短剧、动漫多形态同步开发）；改编范式更重创新（"故事新编"类作品大量涌现）。
- **潘耕**（中国电影文学学会会员）：恰逢《红高粱》发表 40 周年，结合其电视剧改编实践提出三步——"守魂"（守住文学精神内核）、"重构"（顺应媒介规律）、"共振"（穿透时代与媒介，唤醒平凡人心底的英雄梦想）。

### "AI 时代文学的光影表达"访谈要点
蔡骏（中国作协全委会委员）、意千重（云南省作协副主席）、杨蕊（北京电影学院副教授）、张佑晨等对谈：创作者要掌握 AI 技术但需谨慎把握边界；警惕 AI 作品冗余与"平庸的精致"；"守住人之为人的根性"始终是文学对影视的重要启示；在生命现场的创作者才是灵感的发生器。（详细 AI 应用观点见[主题/文学与影视.md](../主题/文学与影视.md)）

### 其他活动
- 吉林省作协与吉视传媒、长影集团签署文学 IP 数字转化暨长影 IP AIGC 转化战略合作协议（王亮、庄严、由志强）。
- 吉林省作协、吉林省广电局、吉视传媒启动"AI 尚吉林"原创文学作品征集。
- "中国文学新力量"·面对面：赵晖、杨蕊、王小枪、管平潮分别走进东北师范大学、吉林动画学院、"这有书"文化空间授课；与会嘉宾参观长影旧址博物馆、吉林文学馆。
- 开幕式由吉林省作协党组书记王亮主持；曹路宝（吉林省委常委、长春市委书记）致辞并发出"扎根大地书写、坚持文影共生、凝聚各方合力"邀约。
