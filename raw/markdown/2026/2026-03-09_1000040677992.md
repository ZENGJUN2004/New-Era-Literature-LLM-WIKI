# 年过花甲，我那无法忘却的文学梦

- **栏目**：中国作家网#理论评论#创作谈
- **发布时间**：2026-03-09 09:29:09
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0309/c404032-40677992.html

年轻的时候，写了小说给一位文学前辈看，前辈教导我说：“文学不是对生活的记录，而是要站在生活的高度俯视生活。”
后来我看到很多文学评论家都反复地强调这句话，我那时候年轻又无知，至少阅历不够，一直不懂如何“站在生活的高度俯视生活”这句“高大上”的话。
直到很多年以后，我成了一个小老板，年近花甲的时候，我似乎真的懂了。但“站在生活的高度俯视生活”谈何容易？
首先，一个生活在社会最底层的人永远无法站在生活的高度，他只能站在最低的位置，他只能仰视别人的生活，又如何去俯视生活？
实际上，作为最底层的人根本就没有生活，只有生存，还奢谈什么俯视生活？大概如此，我才在文学的道路上奋斗几十年而毫无建树？
2026年，我62岁，人生迈过花甲。
我一直担心自己最多活到60岁就会死去，因为我的曾祖父刚好活到60岁死去，我的祖父也是活到60岁死去，我的父亲同样是刚满60岁的第二年春天就离开了人世，我记得很清楚，那时候油菜花刚好凋谢。
父亲的生日是腊月二十日，他满60岁那一天大雪纷飞，正好我们家的牛不见了，家里来了一些客人，可是我和我的哥哥不得不在鹅毛大雪中漫山遍野地找牛。
据说满十的日子下雪下雨都是不吉利的，果然，父亲第二年春天就死了。虽然我一直认为，父亲的病是因为无钱治疗拖出来的，但我还是“迷信”地认为我们家的男性命中注定寿命不长，最多只能活到60岁。
果然，我的大哥30岁那年在建筑工地上出意外抢救无效也死去了。
因此，我总觉得死亡已经离我很近了。但是，我的很多梦想还没有实现。比如文学梦。虽然我只是一个农民，后来又是一个农民工，再后来我是一个个体户，但是，我不死心。我27岁开始发表作品，31岁背井离乡，中间二十多年为了生存而奔波，文学逐渐离我很远。我打工是被迫的，做生意也是被迫的。那只是为了生存，而不是生活。
但作为一个人，不能只为了生存。而人一老，就开始怀旧。
我开始想念在广东打工时的那些工友们，他们绝大多数现在都跟我失去了联系。当年我们同甘共苦，我们各自怀揣着梦想，那时，他们之中大部分都比我年轻。至少，我们都希望有一天能发点小财，发大财估计谁也没有指望过。
我开始对他们有了刻骨铭心的想念，有时候一个人开车在公路上行驶，突然之间莫名其妙地就泪流满面了！几十年过去了，他们到底过得怎么样？尤其是曾经在大年三十来临之前差点跟我一起露宿街头挨饿受冻的几个兄弟，我特别特别地想他们！我想他们想得心里滴血。曾经，我哪怕只能买一个馒头，也是跟他们分着吃的。
跟我保持联系的工友当中，前些年，我知道只有冯生混得不错，他自己开了工厂，有两百多个员工。可是，后来他的工厂也倒闭了，还负债，不得不卖了他的车，然后还用房子去抵押贷款。
我真的希望他们都过得好，我很珍惜我们过去的友谊。我希望还有欢聚的日子，虽然我知道这个想法很不现实。
于是，我打算将我过去打工的生活经历都原原本本地记录下来，那是无比宝贵的记忆。因为我怕有一天这些经历我忘记了，就再也想不起来了。
记录之初，并没有考虑发表与否的问题，因此写得十分轻松自在，没有一点压力，就是记录事实，几乎没有一点艺术加工。文中情节和事件，没有虚构，也没有考虑结构，更没有伏笔之类的技巧。
这些文字读起来可能既不是散文，也不是小说，我只是想要留住那些珍贵的记忆。
最开始，这些打工经历在我们县的报纸上连载，因为是周报，连载一个多月才算完毕。连载完毕，我想起了《读库》这本比较特别的杂志。知道《读库》，是因为作家姜淑梅。她是个非常了不起的作家，60岁才开始学认字，75岁出版第一本书。她的第一篇文章就发表在《读库》杂志。
于是我订阅了一年的《读库》。我想它大概拥有着一批特别的读者。我觉得我的文章都比较适合它，但也没有抱多大希望。好在有投稿邮箱，只需要动动手指就可以发出去，用与不用，也不损失什么。因此我动了动手指，将《上海不是我的家》发到了投稿邮箱。
发出去以后，我就把这事给忘记了。
2020年，快到年底了，一天晚上，我接到了一个从北京打来的陌生 电话，电话 那头的 人，自称是《读库》杂 志的编 辑，说姓张，我 问他叫什么名字，他说叫张立宪。张立宪老师告诉我，他准备采用我的稿子，但需要重新编辑一下，问我同意不同意。老师将我的那篇纪实文章更名 为《上海浮 生》发表后，引 起了一定的反响。大多数评论都是夸我的，但也有少部分读者骂我，我觉得这很正常。
这次投稿完全是意外的收获，我没有想到的收获。
后来，我干脆将我的人生从头开始写起，将我60年的生活经历都记录下来。
现在的这本《田老师打工记》，便是我后30年的生活经历。这本书，没有“站在生活的高度俯视生活”，而是跟生活平视，因为这是我自己的生活，是跟我处于同一社会阶层的人的生活。因此我既没有仰视，也没有俯视，我平视我和我的伙伴们的生活。
如果说这本书精彩的话，那也不是我写得有多么精彩，而是我的生活经历本身所给予的馈赠。我曾一心奔赴生存，却不曾想，这本就是生活的一部分了。
虽然这后30年依然在苦苦挣扎，但对比前30年，我觉得算是很幸福的了。
