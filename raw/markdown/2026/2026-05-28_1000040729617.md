# 苏兰朵：好小说长在泥土里

- **栏目**：中国作家网#理论评论#创作谈
- **发布时间**：2026-05-28 23:05:17
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0528/c404032-40729617.html

《参王》是一个关于东北人参的故事。起因是2025年夏天，我受吉林省作家协会的邀请，参加了一次人参主题的采风活动。
三天的时间安排得很满，从各种博物馆到林下参、园参养殖场，从人参市场到人参化妆品生产公司、销售公司等等，采风团马不停蹄走了很多地方，收获非常大。不仅让我了解了很多富有传奇色彩的古老传说，也让我了解了东北人参产业在当下社会的发展现状。这种传统与现代的交融和碰撞，令我十分激动，采风尚未结束，我已经开始构思这篇小说了。
人物原型也是在采风途中自然而然遇到的。靖宇县山林中的参把头与我们交谈了很久，面对我们关于人参的各种提问，他侃侃而谈，并且不失东北人的幽默。他花白的头发，额头的深纹，粗糙壮硕的手指，甚至他硬邦邦有力道的声音，都给我留下了深刻的印象。人参市场的女老板，自信而诚恳，有令人感叹的世俗的成功，也有对参业发展现状的敏锐洞察和忧虑。她小小的店铺背后，是通达世界各地的生意往来，使我得以窥见卖参人最真实的状态。在抚松现代化园参养殖场的参观令我惊叹。场长淡定地介绍科技的参与使现代养参业发生的巨大变化，一瞬间，人又被带到了似乎可以想象却又难以想象的未来。自然，这些遇到的人，在现实中是彼此都不相识的。但在我赋予他们一个故事后，他们就变成了小说中的苏河、苏寒梅、富大雪和常福星。
那么，我将赋予他们怎样一个故事呢？他们是因为人参而走进我的故事的。所以，在构思故事的过程中，更多的是关于人参的思考。幸运的是，被称作“百草之王”的人参配得上这份思考。它身上那些独有的神奇之处，使它脱离了物质，抵达了精神层面。它既是物质的，又是精神的；既是过去的，又是未来的；既是漫长的、充满想象的、不可见的，又是被赋予历史和传统的、令人敬畏的、可见的。对一个小说家而言，它就是一个无比迷人的象征体！
而它就产自我的家乡，生长在东北大地。每一个东北人，小的时候都听过人参娃娃或人参姑娘的故事。于我而言，人参又是一个充满感情甚至深情的象征体。我无法拒绝写它，我其实早就应该写一写它了！
故事是有根的，它要有所依附。读者朋友们看到的故事，可能是一朵随风摇曳的参苗，开着美丽的参花。而写故事的我，其实更希望你能看到埋在下面的人参。它虽深埋在泥土里，但它可以让参花轻盈地在风中飞舞。
