# “以文为桥 携行互鉴”中俄文学交流活动在辽宁举办

- **栏目**：中国作家网#世界文坛#视点
- **发布时间**：2026-03-18 09:36:49
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0318/c404090-40684142.html

3月12日至13日，“以文为桥 携行互鉴”中俄文学交流活动在辽宁大连外国语大学举办。这是2026年“俄苏文学书友会”的首场活动，也是“俄罗斯太平洋地区文学节”巡回活动的重要一站。此次活动由大连外国语大学和俄罗斯记者联盟滨海边疆区分会联合主办。大连外国语大学校长丛明才，中国作协外联部副主任郑磊，辽宁省作协党组成员、副主席张恒军，大世界俄语学会俄罗斯亚太区分会主席亚历山大·祖布利茨基，高尔基文学院院长、作家阿列克谢·瓦尔拉莫夫出席活动并致辞。俄罗斯作家、出版家、学者与中国作家代表孙惠芬、薛涛等就中俄文学创作与传播展开深入交流。俄罗斯驻沈阳总领事馆代表参加会议。
开幕式上，丛明才介绍了大连外国语大学深耕俄语语言文学教育、推动中外人文交流的办学实践，以及学校在外国语言文学与中国语言文学双轮驱动下的学科发展布局。他表示，大外与辽宁省作协联合成立的辽宁文学海外传播中心，已成为东北亚文学交流的重要载体，而文学作为连接文字、文化与文明的桥梁，是促进民心相通的重要力量，本次活动的举办，正是学校助力中俄人文交流、服务东北亚开放合作的重要实践。
郑磊在致辞中表示，中国作家协会历来重视中俄文学交流。2025年，由中宣部文艺局指导，中国作协外联部牵头，启动了“俄苏文学书友会”项目，该项目通过广泛开展读书活动、夯实学术研究、推动中俄文学互译、加强中俄作家交流、强化传播推广、团结凝结人才等，建立中俄人文交流平台，为外交大局贡献文学力量。今年，中国作协在“俄苏文学书友会”框架下将开展俄苏文学青年学者研修班等系列中俄文学交流活动，为两国作家搭建更广阔的展示交流平台。
到会领导和嘉宾在致辞中，均对中俄文学交流的深厚历史与美好未来寄予期许，认为此次活动将进一步深化两国文学界的相互了解，为中俄人文合作书写新篇。
在主旨报告环节，中国作协全委会委员、辽宁省作协副主席薛涛以《同一块文学陆地：我与俄罗斯的创作出版与交流》为题，结合自身经历勾勒出中俄文学交流的现实图景，介绍了辽宁文学海外传播的丰硕成果；俄罗斯作家、社论家、记者瓦西里·阿甫琴科作《文学在构建人文桥梁中的作用》主题发言，从文学视角阐释了人文交流的深层意义；大连外国语大学学科发展规划处处长彭文钊以《数字人文视角下的比较文学研究》为题，为中俄文学研究与交流打开了数字人文与比较文学结合的新视野；俄罗斯出版家、“远东”全俄文学奖负责人罗曼·柯西金分享《阿尔谢尼耶夫奖在凝聚各国人文界共同体中的作用》，让现场嘉宾对俄罗斯当代文学奖项体系与文学传播路径有了更深入的了解。
本次交流活动还举办了全俄“远东”文学奖推介会、作家创作分享会、中俄作家与师生交流会、中俄出版机构合作圆桌论坛等系列丰富多彩的活动。与会嘉宾围绕文学创作、翻译出版、文化传播等议题展开多维度、深层次的交流探讨，碰撞了思想火花，凝聚了合作共识、增进了作家友谊。
本次活动为中俄文学界搭建了交流合作的新平台，更进一步推动了东北亚区域文学的双向译介与深度对话，助力中俄文明互鉴走深走实，让文学成为连接两国人民情感的坚实纽带。
