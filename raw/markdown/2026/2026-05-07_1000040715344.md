# 从工地到餐桌，一个写作者的“迷宫探险”

- **栏目**：中国作家网#网络文学#动态
- **发布时间**：2026-05-07 16:46:21
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0507/c404023-40715344.html

“我总会相信这个世界上有更好的，更值得我花时间的东西。”
贝斯诺格林（Bethnal Green），读起来有些拗口。它是伦敦东区一个地铁站的名字，也是知乎一位答主的ID。
2014年，贝斯诺格林在英国求学，每天往返于宿舍与校园之间，这站地铁成了他最熟悉的地理标识。于是，他把这个名字当作自己的代号，在知乎敲下了第一行字。十二年间，他的创作坐标从足球延伸到商业，从旅行跨越到美食，像是在文字的丛林里开辟出了一条条岔路。
凭借颇具学术风的“严肃食物写作”，贝斯诺格林入选知乎2025年度新知答主。用他的话说，自己这个从不追热点的“边缘型创作者”被注意到了，“就像一个在巨大的、黑暗的、充满未知的房子中独自探索的人，突然被一束强光照在身上。”
读贝斯诺格林的文字，很少人能想到，他的职业起点是土木工程。
跳出围城，发现世界
填写高考志愿时，贝斯诺格林听从父母建议，报考了土木工程系。对专业谈不上热爱，三大力学挂了两门，做不了设计，也不喜欢背规范，最终只能走向施工一线。毕业后，为了在大环境里站稳脚跟，他投身建筑工程行业，成了基建大军中的一名技术员，在海外基建项目，一待就是五年。
那是真实的、带泥腥味的工地生活。入职首晚就在深坑里摔了一身泥沙；洗澡水里全是铁锈；每天工作十几个小时，连续一年多回不了家。当身边人都在靠打牌、打游戏消磨漫长的荒野时光时，他像《平凡的世界》里的孙少平一样，在逼仄的活动板房里死磕书本。
五年的工地生活，让他明白了两件事：第一，他不想一辈子困在重复的技术施工里；第二，他想去看看更大的世界，而这个机会要靠自己挣出来。
工作第六年，贝斯诺格林跳出围城，选择去英国读MBA。Bethnal Green地铁站成了他每天通勤的必经路，也成了他开启知乎写作的起点。MBA重塑了他的商业逻辑，而足球、旅行和饮食，则填补了他对世界的好奇。作为阿森纳的死忠，他开始写体育商业；作为旅行达人，他拿到了知乎旅行领域的黄标。
更重要的是，旅途中的饮食体验，让他意识到：“吃”才是成本最低、最能触达一个文化核心的方式。
严肃食物写作：在盘子里做学术
定居成都后，贝斯诺格林把人生收缩为三个关键词：饮食、阅读、分享。
他的工作全部围绕食物展开：为饮食杂志深度撰稿；带领外国专业人士在中国做美食考察；为美食纪录片提供文化咨询；深入县域研究食俗、食材，把成果分享给厨师；助力年轻厨师建立自己的烹饪哲学。
把饮食写作定义为“严肃文学”，源于他的执念：一是客观性，不只写舌尖上的主观快感，而是探究食物“应该是什么样”；二是经典性，追求文本的长久生命力。“我希望我的文字在50年后仍有人参考，而不是一种转瞬即逝的情绪消费。”
这种学术范儿在他的文章里随处可见。他想研究“鱼类熟成”，先买来津本光弘的“熟成”“放血”资料啃读；为了搞懂“活缔法”，他以四川成都网红店永乐饭店为样本，连续约访主厨、供应商，蹲守后厨看杀鱼，最终把一个餐厅的技术探索，写成了拆解行业逻辑的技术故事。
他刻意避开温情的感性叙事，选择从供应链和技术演进的角度切入，把一篇美食文章写成了硬核的行业拆解。这篇创作也成为贝斯诺格林严肃食物写作的高光时刻之一。有读者留下评论：知识之外，更有意义的是这番探究过程。
在知乎创作的12年间，贝斯诺格林的作品按照体育、旅行、博物馆、饮食等标签，积累成长长的索引。最受欢迎的专栏“吃·本·道”中，既有对中外饮食文化的溯源，也有对街边烟火饮食的体验，更多的是对食物真真切切的探索和热爱。
“我的好奇心是无限的，但是很幸运的是，能讨论的食物议题也是无限的。我觉得我在闯⼀个无限大的迷宫，太有乐趣了。用⼀个旅行的术语叫‘来都来了’，感觉好像可以无限持续下去。”
在知乎十余年，他积累了三百余篇饮食相关回答，每一篇都是心水之作。对他而言，这不是数据，而是最具象的成就感。
被看见，是对写作者的奖赏
贝斯诺格林把知乎视作 “国内对图文创作者最友好的社区”。
从分享读书笔记，到尝试解决无人触碰的专业问题，他在知乎完成了从“输入”到“输出”再到“共创”的过程。社区的正向反馈，让他在冷门赛道上走得更坚定。
在知乎，他也收获了珍贵的同行与友谊。他与旅行领域答主侃叔一同长途旅行，从对方的旅行方法、阅读与创作中获得诸多启发；也深受食品科学领域答主钱程的影响，尤其认可其食品科学内容的客观性与经典性，在专业问题上时常请教，在创作路上彼此启发。
他入选2025年知乎年度新知答主。他一直觉得自己是在冷门赛道上安静走路的人，不追流量，不凑热闹，只是认真地贴出自己的读书笔记。
他给同行者的建议很朴素：回归创作本身，不要急着求流量。持续阅读，形成价值，警惕那种虚假的掌控感。
对他影响最深的人是阿森纳前主帅温格。温格的理想主义、审美与哲学，潜移默化塑造了他：不给自己设限，相信值得花时间的事物，也让读者觉得，读他的文字“时间花得值”。
对贝斯诺格林而言，写作从来不是追逐掌声，而是一场持续的自我探索。他说：“饮食写作是一个巨大的房子，而我要做的，就是继续在这个房子里上蹿下跳，不停探索。既有客观经典的写作，也可以轻松地把所有见闻和思考‘蒸馏’出来，分享出去。”
从异国的漫长工地到伦敦的地铁站，再到成都街头的烟火气，他始终守着阅读的耐心、分享的真诚、对世界不熄灭的好奇。在这个追求速成的时代，他选择缓慢、笃定、专业地走下去——不慌不忙，在那座名为“饮食”的巨大房子里，继续他的无限探索。
