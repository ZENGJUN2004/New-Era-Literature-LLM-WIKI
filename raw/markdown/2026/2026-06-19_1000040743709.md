# 中国新时代文学研究海外译介会在京举行

- **栏目**：中国作家网#新闻#各地文讯
- **发布时间**：2026-06-19 18:49:34
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0619/c403994-40743709.html

活动现场
6月18日，由中国作家协会新时代文学研究中心与安徽文艺出版社联合主办的中国新时代文学研究海外译介会，在北京国家会议中心BIBF安徽展台主会场举行。中国作家协会2025年重点作品扶持项目《中国新时代文学理论话语建构研究》亮相BIBF并签约韩文版输出。中国作家协会党组成员、副主席吴义勤，《人民文学》副主编陈涛，中国社会科学院民族文学研究所副所长刘大先，中国作家出版集团副总经理崔庆蕾，时代出版传媒股份有限公司党委委员、副总经理兼总编辑张堃，汉学家、埃及苏伊士大学中文系助理教授、第十八届中华图书特殊贡献奖获得者叶海亚，韩国大舶出版传媒社长唐坤，译国译民集团合伙人李凌波，江苏师范大学教授、《中国新时代文学理论话语建构研究》作者郝敬波，时代出版传媒股份有限公司出版业务部主任阮怀伟，安徽出版集团对外合作部主任刘骞，安徽文艺出版社社长姚巍等出席该活动。
中国作家协会党组成员、副主席吴义勤致辞
吴义勤指出，中国作协近年来不断开拓工作思路、创新体制机制，努力推动新时代文学创作与文学批评和谐共进。在中国作协新时代文学研究中心的引导和支持下，更多文学批评家正投身到新时代文学研究中来，富有成效地参与到新时代文学的跟踪、研究与阐释，并以开阔的理论视野进行深入、系统的理论建构。今天推介的郝敬波教授的《中国新时代文学理论话语建构研究》就是对新时代文学系统性梳理和理论化阐释的重要理论著作，是回应时代呼唤、面向文学现场、富有锐气和洞见的研究成果。我们欣喜地看到，越来越多的汉学家和海外出版机构开始聚焦中国新时代文学，这为新时代文学的海外传播和接受提供了更多的可能。接下来即将进行这部著作的韩文版的版权签约，以及该书英文版、中文繁体版等多语种版权的输出，这些都是中国新时代文学研究正在受到海内外读者关注并加快“走出去”节奏的一个有力证明。
安徽文艺出版社社长姚巍致辞
姚巍认为，《中国新时代文学理论话语建构研究》一书，立足于新时代文学的生动实践，从叙事伦理、传统文化、语言变革等多个维度，深入探讨了中国文学在新时代的理论化、系统化建构问题。期待通过这本书，能够为世界提供一把理解中国新时代文学的“钥匙”。此次韩文版签约，不仅是安徽文艺出版社与韩国大舶出版传媒的双向赋能，更是中韩两国在文学理论层面的深度对话。相信通过版权输出与国际合作，中国新时代文学的理论成果将跨越国界，为世界文学理论的百花园增添一抹独特的中国色彩。
活动现场
在随后的座谈环节，郝敬波首先介绍了该书的创作缘起，陈涛、刘大先、崔庆蕾等与叶海亚围绕“中国新时代文学研究如何走出去”展开座谈，从不同维度探讨中国新时代文学的特征、叙事伦理及传统文化传承。
《人民文学》副主编陈涛
陈涛认为，本书从理论层面对诸多现象和问题展开了深入分析，尤其涉及新大众文艺、读者问题、文化传承等新时代文学的重要议题，都有很好的研究呈现。中国文学正在不断“走出去”，大量作品被翻译到海外。这本书作为理论著作，恰好提供了一个桥梁。
中国社会科学院民族文学研究所副所长刘大先
刘大先谈到，以往我们更多的是将文学创作翻译到海外，让外国人了解中国故事；而今天，我们向海外传播的是中国学者如何研究这些作品、如何观察这些文学现象。本书的海外译介，某种意义上标志着中国新时代文学的影响力已提升到新的层面——海外读者开始关注“我们如何看自己”。因此，这本书的海外传播极有价值。
中国作家出版集团副总经理崔庆蕾
崔庆蕾认为，这部著作是对新时代文学创作的及时理论总结。作者敏锐把握新时代文学的时代新变，系统论述新时代文学的审美新质，对文化传承创新问题、新大众文艺现象等重要论题进行了深入讨论，是一部富有创见的学术专著。这部研究著作被翻译到海外，必将成为海外读者了解新时代文学的重要桥梁和通道，也会促进海外读者对新时代文学更加全面而深刻的理解。
汉学家、埃及苏伊士大学中文系助理教授、第十八届中华图书特殊贡献奖获得者叶海亚
叶海亚认为，这部著作不仅对于研究中国文学的海外学者具有重要参考意义，也能帮助普通外国读者了解新时代中国文学的整体面貌。书中对徐则臣的《北上》等当代作品的深入分析，令他收获良多。他期待在不久的将来，能够将其翻译推广至阿拉伯世界，通过文学理论与分析的交流，增进中国与各国之间的友好关系。
韩文版输出签约仪式现场
本次活动的重头戏之一是《中国新时代文学理论话语建构研究》一书的韩文版输出签约仪式。该书是中国作家协会2025年重点作品扶持项目，该著作立足于文学实践分析，总结新时代文学的变化特征，从路径与维度、叙事伦理、传统文化、文学传统、新大众文艺、语言变革等六个方面深入探讨中国新时代文学理论话语建构问题，代表了批评界对于新时代文学研究的最新成果。
签约仪式上，安徽文艺出版社社长姚巍与韩国大舶出版传媒社长唐坤正式签订版权输出协议，这标志着中国新时代文学理论研究在海外传播上迈出了坚实的一步。
据悉，该书的英文版将由英国博思林国际出版社出版，中文繁体版也将陆续出版。
