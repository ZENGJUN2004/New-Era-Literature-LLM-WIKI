# 长篇报告文学《库布其生命歌》作品研讨会在京举行

- **栏目**：中国作家网#新闻#各地文讯
- **发布时间**：2026-03-23 12:09:56
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0323/c403994-40687099.html

2026年3月21日，由中国报告文学学会、内蒙古自治区文学艺术界联合会、鄂尔多斯市文学艺术界联合会主办，内蒙古作家协会、远方出版社承办的肖睿长篇报告文学《库布其生命歌》作品研讨会在中国作家协会举行。中国作协副主席、全国政协文史和学习委员会副主任阎晶明，中国报告文学学会会长徐剑，内蒙古文联党组成员、副主席海山，鄂尔多斯市文联党组成员、副主席赵慧洁，远方出版社总编辑孟庆微出席并致辞。孟繁华、特·官布扎布、包明德、丁晓原、刘颋、李云雷、刘琼、满全、李朝全、刘大先、谭旭东、兴安、张子影、崔庆蕾、王国平、刘浏等专家学者与会研讨。研讨会由中国报告文学学会常务副会长、秘书长梁鸿鹰主持。
阎晶明指出，肖睿始终植根于对家乡鄂尔多斯的书写，长期关注西部生态治理和环境变迁，并把对习近平生态文明思想的理解和思考融入创作之中。《库布其生命歌》以“歌”为名，既是一曲献给库布其治沙历程和治沙群体的深情赞歌，也体现了作家对沙漠存在、沙漠治理及其历史进程的冷静思考。作品既保持了报告文学以真实为生命的原则，又自觉吸纳小说笔法，让原本容易写得单一的题材有了层次、色泽和动感。
徐剑通过视频发言表示，《库布其生命歌》的出版和研讨，意义不仅在于又一部生态题材作品的推出，更在于它让人看见了一种写作精神的延续。肖睿接过了父辈关注家乡、关注沙漠、关注生态变迁的笔，也写出了属于这一代人的理解与回应。作品以古如歌为内在线索，以“起歌”“正歌”“叠歌”的结构徐徐展开，在歌声般起伏的叙述中，把治沙人的身影、生命的体悟和生态观念彼此连缀，让库布其的风沙、草木与人的命运，渐渐汇入同一条叙事的河流。
海山在致辞中表示，近年来，内蒙古文学事业在习近平文化思想指引下守正创新、锐意进取，呈现出人才接续、创作丰硕的良好局面。报告文学作为记录时代、见证历史、讲好中国故事的重要文体，已经成为内蒙古文学版图中的一道亮丽风景。肖睿长期扎根乡土、关注现实，《库布其生命歌》是他深入库布其沙漠一线，沉下心采访、俯下身倾听，以数年心血打磨而成的重要成果。作品没有停留于成果展示和数据罗列，而是把笔触伸向一个个具体的人、一段段真实的往事和一次次与风沙的较量，在广袤沙海与人间烟火之间，写出了库布其从“沙进人退”到“绿进沙退”的艰辛历程，也写出了几代治沙人在漫长岁月中坚守奉献、接续奋斗的精神谱系。
赵慧洁表示，鄂尔多斯是一片有着深厚历史积淀的土地，也是一座不断生长着希望与梦想的暖城。近年来，这里在绿色发展中焕发出新的生机，在时代奔涌中发出属于自己的回响。《库布其生命歌》的出版，正是鄂尔多斯文艺创作结出的又一枚沉甸甸的果实。它不仅是本土作家深深扎根家乡大地、倾情书写时代变迁的真诚之作，也让人看到了鄂尔多斯青年作家对脚下土地的深情、对现实生活的体察，以及用文学回应时代的责任与担当。
与会专家一致认为，《库布其生命歌》坚持以人民为中心的创作导向，紧扣时代主题和生态文明建设实践，是一部兼具文学价值、现实意义和文献意义的生态报告文学作品。作者肖睿长期深入库布其实地走访调研，以细腻鲜活的细节，将当地生态变迁、历史传统与人文风情融为一体，让宏大题材兼具扎实的文学质感与真挚的情感温度。作品以“古如歌”谋篇布局，巧妙融合民歌传说与治沙实践，文化意蕴深厚，兼具鲜明地域特色与深邃的生命哲思。作品突破“征服自然”的传统叙事范式，树立人与自然和谐共生的生态理念，实现了生态书写观念的重要跃升。《库布其生命歌》早已超越了单一题材写作，它既像一份写给库布其的备忘录，也像一部风物志、心灵史，既写出了治沙奇迹和中国经验，也写出了这片土地上的苦辛、坚守与希望。全书篇幅凝练而内容厚重，在文体融合和叙事艺术上都作出了可贵探索，展现了青年作家面对重大现实题材时难得的定力与诚意。
《库布其生命歌》由远方出版社出版，其节选《库布其——我的生命歌》发表于《鄂尔多斯》2025年第12期，入选“2025年中国报告文学优秀作品推荐名单”。作为肖睿的家乡刊物，《鄂尔多斯》杂志始终是他文学创作道路上的重要见证者与推动者。
肖睿在发言中表示，家乡刊物不仅给予他持续不断的创作灵感和精神力量，也为他的作品走向更广阔的文学舞台提供了宝贵平台。
