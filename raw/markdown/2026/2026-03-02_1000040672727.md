# 全国人大代表冉冉：大山里长出的民族文学，何以让世界共情？

- **栏目**：中国作家网#新闻#各地文讯
- **发布时间**：2026-03-02 08:22:09
- **来源**：1
- **原文链接**：http://www.chinawriter.com.cn/n1/2026/0302/c403994-40672727.html

“当前，中国的民族文学创作正呈现出多元共生、固本开新的鲜明特征。”全国人大代表、中国少数民族作家学会会长、无党派人士冉冉近日接受中新网独家专访说，过去，民族文学创作侧重民族内部的文化书写，如今已转向“美美与共”的交融叙事，越来越多的作品展现出各民族交往交流交融的历史与现实。
从重庆酉阳大山里走出来的冉冉是一名土家族作家，数十年来始终耕耘民族文学创作。她的创作跨越诗歌、小说、散文等多种体裁，扎根民族文化的深厚土壤。
这些年，冉冉的足迹遍布渝鄂湘黔民族村寨以及内蒙古草原等地，通过参与研讨会、进行文学采风等方式，深入了解民族文学的传承及文旅融合的实践路径。
在调研中，她发现基层创作者缺乏专业指导和资源支持，而且部分民间艺人年事已高，文化传承面临断代风险。同时，部分作品停留在民族元素、民俗风情的浅表呈现，缺乏历史纵深和现实关怀，而优质的民族文学作品存在数字化传播能力滞后的问题，难以突破文化圈层。这些因素都制约着民族文学深入发展与广泛传播。
冉冉说，她的写作中有不少土家族文化元素，比如长篇小说和长诗中的哭丧、阳戏、古寨和吊脚楼等，这既是故事生成演进的背景，也承载着人物的情感共鸣。这些民族元素与现实生活有机融合，更能有效展现民族文化的韧性与活力。
近年来，民族文学的创作视野拓展至社会生活的各个领域，乡村振兴、生态文明、历史叙事等题材占据重要地位。在冉冉看来，这是民族文学与时代同频共振的必然结果，同时也是各民族作家扎根现实生活的生动体现。
她进一步阐释，民族地区大多处于乡村或生态保护区，乡村振兴的实践、生态环境的变迁、民族历史的传承，都是作家真切的生活体验，也让这类题材选择具有了必然性。这些题材的书写，传达的是各民族作家的时代观察和对美好生活的向往。
在冉冉看来，民族文学与影视、文旅、数字媒体等领域的融合不断加深，“跨界融合”已成常态，这拓展了民族文学的传播路径和影响力。此外，越来越多的民族文学作品从过去单纯的风景描写转向对人与自然关系的深度探讨，实现从“观察自然”到“思考文明”的跨越。
在把握当下创作趋势的同时，冉冉也对民族文学的潜力领域充满期待。她认为，网络文学、儿童文学等领域都有望成为民族文学的新增长点。网络文学凭借传播优势，能够吸引更多的读者；儿童文学则可以通过生动有趣的叙事，让民族故事代代相传。此外，将民族元素与当地文旅资源结合，打造沉浸式文化体验，既能拓展文学的价值边界，又能推动民族地区文化产业发展。
“我理想中的民族文学图景是‘百花齐放、交融共生’。”冉冉说，随着基层创作者获得越来越多的资源支持和权益保障，传播渠道也愈发畅通多元，民族文学作品能够走进校园、走进社区、走向国际，生动展现各民族美美与共、交融共生的故事。
